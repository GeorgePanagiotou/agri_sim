## New: Area explorer (any area)

`app/area_explorer.py`, details in [docs/area_pipeline.md](docs/area_pipeline.md).

- **Choose or create an area.** Pick a prepared area, or draw a box (β‰¤ 1Β° Γ— 1Β°) and click *Create area*.
- **Start or resume data preparation.** It runs in the background, one run per area: a lock file refuses a second
  run.
- **Warnings shown before a run:**
  - a full run takes a few hours;
  - IMERG and NASADEM need an Earthdata login.
- **Settings Β· NASA Earthdata login.**
  - Checked against urs.earthdata.nasa.gov.
  - Kept in the browser session only.
  - Passed only to the run the user starts (`EARTHDATA_USERNAME/PASSWORD`), never saved.
  - Without it, the server's `~/.netrc` is used.
- **Tabs:**
  - **Data status:** the pipeline steps.
  - **Climate & crop fit:** KΓ¶ppen class from NASA POWER normals + FAO GAEZ crop suitability.
  - **Recent climate:** IMERG vs POWER via the API.
  - **Sowing & risk:** the area's own engines.
  - **ML training data.**
  - **Field outlook (ML):** forward-test scores vs the 5-year baselines, and the season-2027 crop-probability map.
- **Climate verdict at the top of every area.** The rules were built for Evia, which is Csa:

  | Verdict | Climates |
  |---|---|
  | Calibrated | Cs* (Mediterranean) |
  | Partly | BSk/BSh with winter rain; Ds* |
  | Not calibrated | Everything else, and the whole Southern Hemisphere (reversed seasons) |

  Checked live: Evia and Messara Csa Β· Konya Dsa Β· Iowa Dfa Β· Pampas Cfa.
